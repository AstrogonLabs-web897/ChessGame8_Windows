# ♟️ ChessGame8 Windows

**ChessGame8_Windows** — это современное шахматное приложение для операционной системы Windows, разработанное на платформе **.NET** с использованием графического интерфейса **WPF (Windows Presentation Foundation)**. Проект спроектирован по архитектуре MVVM и включает в себя собственного умного ИИ-оппонента.

---

## 🚀 Основные возможности (Features)

* **Асинхронный игровой цикл:** Стабильная работа интерфейса без зависаний благодаря использованию (`TaskCompletionSource` и `SemaphoreSlim`).
* **Умный ИИ (Smart AI):** Встроенный компьютерный оппонент, работающий на базе алгоритма **Negamax** с **Альфа-бета отсечением** и эвристической оценкой позиции (материал + мобильность фигур).
* **Контроль времени:** Встроенный шахматный таймер хода для каждого игрока (`DispatcherTimer`).
* **Система сохранений:** Возможность сохранения текущего состояния партии в формат **JSON** с помощью библиотеки `Newtonsoft.Json` и последующей корректной загрузки.
* **Интуитивный UI:** Поддержка перемещения фигур с помощью мыши (**Drag-and-Drop**), а также дублирующее управление с клавиатуры.

## 🛠️ Стек технологий (Tech Stack)

* **Язык программирования:** C# 12 / C# 13
* **Платформа:** .NET 8.0 / .NET 9.0 (WPF)
* **Архитектурный паттерн:** MVVM (Model-View-ViewModel)
* **Сторонние библиотеки:**

  * `Newtonsoft.Json` (для сериализации игрового состояния)
  * `CommunityToolkit.Mvvm` (управление командами `RelayCommand`)

## ⚙️ Установка и запуск (Installation & Setup)

1. Клонируйте репозиторий к себе на компьютер:

   ```bash
   git clone https://github.com/AstrogonLabs-web897/ChessGame8_Windows
   ```

2. Откройте файл решения `ChessGame8.slnx` в **Visual Studio 2022 / 2026**.
3. Убедитесь, что все зависимости NuGet восстановлены автоматически.
4. Выберите конфигурацию **Debug** или **Release** и нажмите **F5** (Запуск).
